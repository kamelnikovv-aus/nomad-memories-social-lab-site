Nomad Memories Social Lab

Privacy Policy.

Last updated: 31 October 2026

This policy explains how Nomad Memories Social Lab handles information obtained through authorized, read-only YouTube, Instagram, and TikTok API access.

1. Data we receive

Depending on the platform and permissions granted, the app may receive account identifiers and display names; optional account statistics such as follower counts; public video identifiers, titles, descriptions or captions, hashtags, publication times, durations, and links; and available performance counts such as views, likes, comments, and shares.

The app also receives OAuth access and refresh tokens needed to maintain authorized API access. It does not ask for your social media password. Metrics that an API does not provide are recorded as unavailable, not as zero.

2. How we use the data

Data is used to build local reports, compare videos within their platform and observation windows, and track changes through new timestamped snapshots. The integration is read-only: it does not use these permissions to publish, modify, or delete content or manage comments.

3. Where data is stored

Video records, account metadata, and metric snapshots are kept in a local SQLite database on the app operator’s device. OAuth tokens are stored locally in separate, Git-ignored files and are not placed in the public website, source repository, or SQLite database. TikTok and Instagram token storage uses Windows DPAPI for the current user; other platform token files remain local and outside the public repository.

This website is a static information site hosted by GitHub Pages. It has no sign-in form, tracking script, or analytics cookie. GitHub may process technical visit information under its own policies when serving the pages.

4. Protection and sharing

Local access controls, separate token files, and DPAPI where implemented help protect credentials. API requests are sent to the relevant platform using its official endpoints. The app does not sell account data or publish local analytics records through this website.

5. Retention, revocation, and deletion

Local video records and snapshots remain until the app operator deletes them; earlier observations are not automatically removed when a new snapshot is saved. You can revoke OAuth access in the connected-app settings of TikTok, Google/YouTube, or Meta/Instagram. Revocation prevents future authorized collection, but existing local records remain until deleted.

To request deletion of locally stored account data or tokens, contact the app operator using the email below. The operator can remove the local token file and the relevant local records and backups. This static website cannot process deletion requests automatically.

6. Contact and updates

Questions about data handling, access, or deletion can be sent to the app operator. This policy will be updated here if data practices change.
